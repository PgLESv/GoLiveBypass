# GoLiveBypass 2.1.4

Lançamos a versão 2.1.4 do GoLiveBypass.

Esta versão formaliza o projeto como fork independente mantido por **PgLESv** com tracking contínuo do upstream (**bezumiya/GoLiveBypass**), remove o sistema legado de reporte de bugs para serviços de terceiros e aprimora a robustez dos scripts PowerShell.

## O que mudou

- **Oficialização de Fork e Atualização de Referências (PgLESv):**
  - O repositório passa a operar explicitamente como fork mantido por **PgLESv**, com ciclo de release, builds e pipelines de atualização independentes.
  - Documentação (`README.md`), plugin Vencord/Equicord (`goLiveBypass/manifest.json`, `native.ts`, `index.tsx`), scripts instaladores (`installer/`) e standalone (`standalone/`) agora apontam para os endpoints e links oficiais de `PgLESv/GoLiveBypass`.
  - Distinção clara e respeitosa entre o autor original (`bezumiya`) e o mantenedor do fork (`PgLESv`).

- **Remoção do Sistema Legado de Bug Report (`api.skyplaceia.com`):**
  - Removido o botão de relatório de bugs no rodapé da GUI e na tela de logs, bem como a janela modal de formulário e a integração HTTP com o serviço externo `api.skyplaceia.com`.
  - Excluído o arquivo `golive-gui/electron/bugreport.ts` e simplificados os scripts de linha de comando (`golivebypass-standalone.sh`, `GoLiveBypass-Standalone.ps1`, `golivebypass-installer.sh` e `GoLiveBypass-Installer.ps1`), eliminando requisições não solicitadas em caso de falhas locais.
  - A funcionalidade local "Copiar diagnóstico" continua disponível e pode ser anexada manualmente a [Issues no GitHub](https://github.com/PgLESv/GoLiveBypass/issues).

- **Robustez e Codificação PowerShell:**
  - Preservação estrita do Byte Order Mark (UTF-8 BOM) nos scripts PowerShell para garantir 100% de compatibilidade sem erros de análise léxica em caixas de desenho TUI e setas sob o Windows PowerShell 5.1 nativo.
