# GoLiveBypass 2.1.9

Lançamos a versão 2.1.9 do GoLiveBypass.

Esta versão traz melhorias no processo de build e release no GitHub Actions, simplifica a interface gráfica removendo o botão de suporte do Discord e elimina a opção de canal beta para manter o fork dedicado exclusivamente a versões estáveis.

## O que mudou

- **Versionamento Dinâmico na Build do GitHub Actions:**
  - Os jobs de empacotamento Windows, Linux e macOS no workflow `build-gui.yml` agora sincronizam dinamicamente a versão em `golive-gui/package.json` a partir da tag disparada (ex.: `v2.1.9`), garantindo paridade exata entre o release do GitHub e os metadados embutidos no executável pelo `electron-builder`.

- **Interface Gráfica Mais Limpa e Focada:**
  - Removido o botão flutuante de suporte com link para o Discord.
  - Removido o seletor de "Canal beta" no diálogo de configurações da GUI, assegurando que o aplicativo permaneça no canal estável padrão.

- **Fluxo de Release Simplificado:**
  - Eliminados jobs e condicionais de canal beta no workflow do GitHub Actions, desativando marcações de pré-lançamento não utilizadas no fork.
