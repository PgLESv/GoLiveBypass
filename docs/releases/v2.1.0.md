# GoLiveBypass 2.1.0

Lançamos a versão 2.1.0 do GoLiveBypass.

Esta versão expande a integração nativa com o ProtonVPN, adicionando suporte completo a planos pagos, catálogo mundial de servidores e otimização de latência específica para o Brasil.

## O que mudou

- **Suporte a assinaturas pagas da ProtonVPN:**
  - Consulta automática à API `/vpn/v2` para detectar planos pagos (`Proton Family`, `Proton Plus`, `Proton Unlimited`, etc.) com `MaxTier >= 2`.
  - Exibição de badge estilizado com a identidade visual da Proton ao lado do status da conta, destacando o plano ativo.
  - Acesso liberado a todos os mais de 18.200 servidores Plus mundiais sem limitar a conexões gratuitas.

- **Desbloqueio global de servidores em mais de 140 países:**
  - O seletor de rotas "Escolha sua rota" agora agrupa servidores por continentes:
    - **América do Sul (menor latência / ping ultrabaixo):** Argentina (~45ms), Chile (~70ms), Uruguai (~50ms), Colômbia, Peru, Equador, Paraguai e Bolívia.
    - **América do Norte:** Estados Unidos, Canadá e México.
    - **Europa:** Portugal, Espanha, Reino Unido, Alemanha, França, Holanda, Suíça, Itália, etc.
    - **Ásia e Oceania:** Japão, Cingapura, Austrália, Nova Zelândia, Coreia do Sul, Taiwan, etc.
    - **Todos os países (A-Z):** Lista alfabética com 145 países disponíveis na ProtonVPN, com bandeiras emoji e nomes traduzidos em português nativos (`Intl.DisplayNames`).

- **Otimização inteligente de latência regional para o Brasil:**
  - No modo "Automático · menor ping", o algoritmo exclui saídas com IP brasileiro (`BR`) para que o Discord não bloqueie o Go Live, selecionando automaticamente servidores vizinhos ultra-rápidos na América do Sul (como Argentina a ~45ms ou Chile a ~70ms) com fluidez muito superior à rota tradicional dos EUA (~140ms).

- **Correção na autenticação ProtonVPN:**
  - Atualizado o cabeçalho de versão para `linux-vpn-cli@5.6.10` com `x-pm-apiversion: 3` (arquitetura v5), corrigindo o erro `this version of the app is no longer supported (code 2028)` causado pela descontinuação da API v4 legada pela Proton.

- **Reutilização de sessão salva sem prompt no terminal:**
  - O backend do `proton-confgen` agora recupera o usuário e valida o token persistente diretamente do arquivo salvo sem depender de entrada interativa via stdin.
