# GoLiveBypass 2.1.3

Lançamos a versão 2.1.3 do GoLiveBypass.

Esta versão corrige uma falha crítica no auto-update do Windows para executáveis portáveis (`GoLiveBypass-*.exe`).

## O que mudou

- **Auto-Update no Windows Portable (EBUSY / Código 32):**
  - **Causa Raiz:** O wrapper NSIS do electron-builder mantém um handle com bloqueio de leitura exclusiva (`FILE_SHARE_READ`) sobre o arquivo `.exe` durante toda a execução. A tentativa do aplicativo de substituir a si mesmo (`renameSync` para `.old`) antes de fechar resultava invariavelmente em erro de permissão do sistema operacional (`EBUSY: resource busy or locked`).
  - **Solução:** O fluxo de atualização agora desacopla a substituição do executável para um helper externo silencioso (`.bat` executado via `wscript.exe` com janela oculta). O novo binário é validado via SHA-256 e o Electron é encerrado com `app.quit()`.
  - **Substituição Confiável:** O script batch aguarda a liberação do lock em um loop seguro com `move /y`, substitui o executável no caminho original preservando atalhos e inicializações automáticas, inicia a nova versão e limpa os arquivos temporários.
