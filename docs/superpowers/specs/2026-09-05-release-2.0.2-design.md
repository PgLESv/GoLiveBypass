# Release 2.0.2 — hotfix WireGuard Windows/Linux

## Objetivo

Consolidar todas as correções presentes na `main`, gerar instaláveis Linux e Windows da versão estável `2.0.2`, validar o ciclo WireGuard no Windows 11 e publicar os dois artefatos na release.

## Escopo técnico

- Manter a prontidão WireSock não bloqueante quando a telemetria opcional estiver ausente.
- Preservar rollback para falhas reais e serialização de ativação, troca de rota, desativação e restauração.
- Manter a validação Linux de namespace, handshake, tráfego e gateway, com recuperação limitada.
- Atualizar versão, changelog e checksums; não introduzir fallback de proxy/Tor.

## Verificação

- Vitest, TypeScript, paridade do standalone e build AppImage/Windows.
- VM Windows 11: instalar/abrir, ativar, confirmar WireSock/Discord, observar estabilidade, desativar e restaurar.
- Publicar `GoLiveBypass-2.0.2.AppImage` e `GoLiveBypass-2.0.2.exe` na release `v2.0.2`.
